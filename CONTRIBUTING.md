# Contributing

## Development workflow

1. Create a branch from the default branch.
2. Make a focused change.
3. Run the relevant tests and checks.
4. Open a pull request with a clear summary and testing notes.

## Commit messages

Use concise, imperative commit messages. Keep unrelated changes in separate commits.

## Pull requests

Describe what changed, why it changed, and how it was verified. Update documentation when behavior or setup changes.
